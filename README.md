# חניה ליד הקיבוץ — בלומפילד

אותו ממשק של הגרסה המקורית, עם משיכת נתונים אמיתיים ממקורות רשמיים. ״כנראה״ מופיע לצד הכותרת, ו״באזור״ הוסר מהשורה הדקה.

## הנתונים

העדכון רץ ב־GitHub Actions מדי חצי שעה (בדקות 13 ו־43), גם כשהאתר סגור. אין צורך במפתח API, הרשמה לשירות scraping, או מנוי בתשלום. GitHub עשוי לעכב או לדלג על ריצות מתוזמנות; לכן האפליקציה בודקת בעצמה את גיל המידע.

| מקור | מה נמשך |
| --- | --- |
| היכלי הספורט — פיד iCalendar לספורט | אירועים עם מיקום מפורש בבלומפילד |
| היכלי הספורט — פיד iCalendar לתרבות | הופעות ואירועי תרבות בבלומפילד |
| ההתאחדות לכדורגל — מכבי ת״א | משחקים, מועדים ואצטדיונים |
| ההתאחדות לכדורגל — הפועל ת״א | משחקים, מועדים ואצטדיונים |
| האתר הרשמי של מכבי ת״א | הצלבת שעות, מיקום ומועדים לא סופיים |
| API רשות הספורט העירונית | לוח אירועים מפורסם עד שנה קדימה, עם בדיקת עימוד |
| האומן 17 — האתר הרשמי | אירועים סמוכים עם תאריך מלא מפורש ושעת פתיחת דלתות כשפורסמה |

אלו שבעה פידים מחמישה מפרסמים. פידים של אותו ארגון נספרים כמפרסם אחד. ההתאחדות עלולה להחזיר 403 משרתי GitHub; אין להציג את העותק השמור כאילו נבדק עכשיו. האומן מפרסם גם פוסטים ללא תאריך מלא: רק רשומות עם תאריך מפורש נקלטות, והמקור מסומן כחלקי עם מספר הרשומות שלא ניתן היה לתארך. גגרין ודופלקס נבדקו אך חסמו גישה מהסביבה; הם אינם מקורות מחוברים כרגע. אין כיסוי מובטח לכל אירוע בסביבה.

## אמינות וקבלת החלטות

- הנתונים נשלפים ב־GitHub Actions, ללא מפתחות חשופים, תלות בטלפון המבקר או פרוקסי ציבורי. עדכון אחת לחצי שעה הוא תזמון מבוקש, לא הבטחה של GitHub לזמן ריצה.
- לכל מקור נשמרים מצב המשיכה, מועד הבדיקה ומועד ההצלחה האחרון. כשל אינו מרענן את גיל העותק השמור. מידע בן יותר משעתיים אינו נחשב עדכני.
- זיהוי אחיד של קבוצות מאחד כפילויות. לכל אירוע נשמר `evidence`: תאריך, שעה, מקום, ביטול, מקור, מפרסם ומועד תצפית. `independent_publishers` סופר רק מפרסמים נוכחיים עם שעה סופית; `verification` מבדיל בין הצלבה, מקור רשמי, תכנון, סתירה ועותק ישן.
- בעת שינוי תאריך, שעה, אצטדיון או ביטול, תצפיות נוכחיות מקבלות קדימות על פני עותקים ממקור שכשל. ההשוואה כוללת תאריכים במרחק עד שלושה ימים. סתירה בין מקורות נוכחיים נשארת גלויה; אירוע ישן שאין עליו תצפית חדשה נשמר כאזהרה.
- **ירוק — כנראה יש חניה:** לא נמצא אירוע לתאריך ולחלונות שחוצים אליו חצות, ולפחות שני מפרסמים עצמאיים של לוחות האצטדיון עדכניים, ובהם מפעיל האצטדיון או הרשות העירונית. שני פידים של אותו גוף אינם מספיקים. מקור משלים שנכשל אינו משבית לבדו את כל הימים הירוקים. כשחלק מהמקורות חסרים מוצגת הסתייגות.
- תאריך רחוק אינו נהפך אוטומטית לאפור. עד שנה קדימה אפשר להציג הערכה לפי הלוחות שפורסמו, ובטווח שמעל 14 ימים כתוב שעוד ייתכנו שינויים. זו הבחנה בהיקף הראיות, לא אחוז ביטחון מחושב או הוכחה שאין אירוע.
- **אדום — כנראה אין חניה בחלון המצוין:** קיים לפחות אירוע נוכחי עם שעה ומיקום סופיים וללא סתירה. אירוע נוסף שאינו סופי לא מבטל חלון עומס ידוע; הוא מוצג עם הסתייגות.
- **אפור:** אירוע מתוכנן ללא פרטים סופיים, מידע ישן על אירוע, סתירה ממשית, או שאין די לוחות עצמאיים ועדכניים כדי להעריך יום ללא אירוע. אין רשימת דוגמה או שעות מומצאות; `00:00` בהתאחדות נחשב לשעה שטרם נקבעה.
- מקורות עם פענוח חלקי יכולים לתמוך באירוע מפורש שנקלט, אך אינם נספרים כראיה להיעדר אירועים.
- חלונות העומס הם כללי הערכה: בלומפילד — שלוש שעות לפני ועד שעתיים וחצי אחרי ההתחלה; האומן — שעה לפני פתיחת דלתות ועד שש שעות אחריה. אין מדידת קהל או חניות, ואין כאן הודעת חסימת כביש רשמית.
- חציית חצות נשמרת בתאריך הנכון. אירועים עם שעה לא סופית או מקור ישן אינם מיוצאים ליומן. ״מקורות ועדכניות״ מציג מצב ומועד הצלחה לכל מקור בנפרד.

אפשר לומר שהאתר משתמש בפרסומים אמיתיים ממקורות רשמיים, ומצליב פרטי אירועים כשיש כמה מפרסמים זמינים. אי אפשר לומר שזמינות החניה עצמה נמדדה או אומתה.

## הפעלה ובדיקות

Python 3.11 ומעלה ו־Node 22; אין תלויות להתקנה.

```sh
python scripts/update_games.py
python -m unittest discover -s tests -p 'test_*.py'
node --test tests/data.test.cjs
```

קובצי האתר הם `index.html`, `data.js`, `games.json`. `data/source-cache.json` שומר את התגובה המוצלחת האחרונה מכל מקור, כדי שריצה תקולה תוכל להציג מידע חלקי ביושר.

## האתר הציבורי והתחזוקה

[פתיחת האפליקציה](https://kibbutz-entrance.github.io/bloomfield-parking/)

המאגר והאתר פורסמו לציבור באישור מפורש של המשתמש ב־2 בנובמבר 2026. GitHub Pages מוגדר לפרסום באמצעות Actions. כל שינוי ב־main, ריצה ידנית או הריצה המתוזמנת מרעננים את הנתונים ומפרסמים את האתר. אין משתנה הפעלה נוסף ואין מפתח API.

פריסת הייצור הראשונה אומתה בריצה 41530238351: בדיקות, משיכה, שמירת הנתונים ופריסה הצליחו. ארבעת פידי הליבה התעדכנו בהצלחה; שני פידי ההתאחדות החזירו 403 ומוצגים כמקורות משלימים שאינם זמינים. גם כתובת האתר הציבורית וקובץ הנתונים נבדקו בפועל.

לבדיקת תקלה: לפתוח את הריצה האחרונה ב־Actions, לבדוק את שלב Pull official public sources ואת מצב כל מקור ב־games.json. אין לעדכן ידנית חותמת זמן של מקור שנכשל. כשלי מקור נשמרים ומוצגים גם כשהפריסה עצמה מצליחה.

## ביקורת ארכיטקטורה — 3 בנובמבר 2026

הוסרו חסימת הירוק הגורפת מעבר ל־14 יום והדרישה להצלחת כל פיד ליבה. נוספו מניין מפרסמים עצמאיים, קדימות לעדכון נוכחי על פני עותק ממקור כושל, ראיות לכל אירוע, פענוח חלקי מפורש, טווח משיכה של שנה לרשות העירונית והאומן 17. בדיקה חיה מקומית החזירה אירועים רשמיים; הפריסה אומתה בריצה 41617096002: ארבעה פידים מלאים, האומן חלקי ושני פידי ההתאחדות חסומים עם גיל העותק המקורי. המשחק ב־6 בנובמבר הוצלב בין שלושה מפרסמים נוכחיים. 31 בדיקות Python ו־24 בדיקות Node עברו; נבדקו באתר יום ירוק רחוק, שני חלונות עומס נפרדים ויום עם אירוע לא סופי. הבדיקות מכסות כשל רחב, קוורום, כפל ספקים, סתירות, שינוי שעה/מקום/תאריך, ביטול, מקור חלקי, מועדים לא סופיים וחציית חצות.
