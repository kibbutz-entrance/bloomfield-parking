# חניה ליד הקיבוץ — בלומפילד

אותו ממשק של הגרסה המקורית, עם משיכת נתונים אמיתיים ממקורות רשמיים. ״כנראה״ מופיע לצד הכותרת, ו״באזור״ הוסר מהשורה הדקה.

## הנתונים

העדכון רץ ב־GitHub Actions מדי חצי שעה (בדקות 13 ו־43), גם כשהאתר סגור. אין צורך במפתח API, הרשמה לשירות scraping, או מנוי בתשלום. GitHub עשוי לעכב או לדלג על ריצות מתוזמנות; לכן האפליקציה בודקת בעצמה את גיל המידע.

| מקור | מה נמשך |
| --- | --- |
| היכלי הספורט — פיד iCalendar לספורט | אירועים עם מיקום מפורש בבלומפילד |
| היכלי הספורט — פיד iCalendar לתרבות | הופעות ואירועי תרבות בבלומפילד |
| ההתאחדות לכדורגל — מכבי ת״א | משחקים, מועדים ואצטדיונים |
| ההתאחדות לכדורגל — הפועל ת״א | משחקים, מועדים ואצטדיונים |
| האתר הרשמי של מכבי ת״א | הצלבת שעות, מיקום ומועדים לא סופיים |
| API רשות הספורט העירונית | לוח אירועים מפורסם בטווח הבדיקה |

אלו שישה פידים מארבעה אתרים רשמיים. שני הפידים של היכלי הספורט ושני הפידים של ההתאחדות חולקים ספק בכל זוג. בהרצה משרתי GitHub ההתאחדות החזירה 403; היא נשארה מקור משלים עם סטטוס גלוי. מקורות הליבה הם היכלי הספורט, האתר הרשמי של מכבי ורשות הספורט העירונית. מקור משלים שלא זמין לא מתחזה למקור שנבדק מחדש. שינויים מתגלים רק אחרי פרסומם במקור והרצת העדכון. אירועים פרטיים שלא פורסמו לא בהכרח יופיעו. אין חיישני תפוסת חניה.

## אמינות

- נתונים נשלפים בשרת של GitHub ולא מטלפון המבקר: אין מפתחות חשופים ואין תלות ב־CORS או בפרוקסי ציבורי.
- אין רשימת דוגמה שמתחזה למידע עדכני. שעה שלא פורסמה נשארת ריקה; `00:00` בהתאחדות נחשב לערך שעדיין לא נקבע.
- מנגנון הצלבה מאחד שמות שונים לאותן קבוצות ומסמן חילוקי דעות בשעה, בתאריך, בביטול או באצטדיון.
- משחק בית שמיקומו עדיין לא פורסם נשאר מועמד לא ודאי; לא מסיקים ממנו שאין אירוע.
- כל מקור שומר את מועד ההצלחה האחרון שלו. כשל ברענון שומר את הנתונים הישנים ואת גילם האמיתי.
- סימון ירוק דורש שכל ארבעת הפידים החיוניים (היכלי הספורט — ספורט ותרבות, מכבי ורשות הספורט) נבדקו בהצלחה בשעתיים האחרונות, ושהיום המבוקש בטווח 14 הימים הקרובים. גם אז מדובר בהערכה לפי פרסומים, ולא בהבטחה לחניה.
- אירוע ידוע אך ישן, סותר או לא סופי מוצג כלא ודאי. תאריך רחוק ללא אירוע מוצג כחוסר מידע.
- חלון העומס המשוער: שלוש שעות לפני תחילת האירוע ועד שעתיים וחצי אחריו. זה כלל הערכה, לא הודעת חסימת כביש רשמית. מוגדר ב־`scripts/update_games.py`.
- חציית חצות נשמרת בתאריך הסיום הנכון, גם ביומן. אירועים בלי שעה סופית לא מיוצאים ליומן.
- ״מקורות ועדכניות״ בתחתית האתר מציג את מצב המקורות ואת זמן העדכון.

## הפעלה ובדיקות

Python 3.11 ומעלה ו־Node 22; אין תלויות להתקנה.

```sh
python scripts/update_games.py
python -m unittest discover -s tests -p 'test_*.py'
node --test tests/data.test.cjs
```

קובצי האתר הם `index.html`, `data.js`, `games.json`. `data/source-cache.json` שומר את התגובה המוצלחת האחרונה מכל מקור, כדי שריצה תקולה תוכל להציג מידע חלקי ביושר.

## הפעלת GitHub Pages

המאגר הוכן כפרטי. הפרסום הציבורי ממתין לאישור המשתמש. בחשבון הנוכחי GitHub מציג שנדרש מאגר ציבורי או שדרוג כדי להפעיל Pages.

לאחר אישור חשיפת האתר והקוד:

1. להפוך את המאגר לציבורי ב־Settings → General → Change repository visibility.
2. ב־Settings → Pages לבחור GitHub Actions כמקור הפרסום.
3. ב־Settings → Secrets and variables → Actions → Variables להוסיף `PAGES_ENABLED` עם הערך `true`.
4. ב־Actions להריץ ידנית את `Refresh official schedules and deploy` ולאמת הצלחת build ו־deploy ואת כתובת האתר שהריצה מחזירה.

עד להפעלת `PAGES_ENABLED`, מנגנון העדכון והבדיקות פועל אך אין פרסום אתר. לא הוזן מפתח, לא נרכש מנוי ולא שונתה תוכנית החשבון.
